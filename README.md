# 🍽️ Food Munch – Responsive Food Ordering Website

## 📌 Project Overview

Food Munch is a responsive food ordering website developed using **HTML5 and CSS3**. It provides an attractive and user-friendly interface where users can explore different food categories, learn about food services, and view delivery and payment information.

The website focuses on clean layouts, appealing visuals, and responsive design to provide a smooth browsing experience across different screen sizes.

## ✨ Features

- **Navigation Bar:** Easy navigation between different sections of the website.
- **Banner Section:** Attractive landing page with food-related content and action buttons.
- **Why Choose Us:** Highlights food quality, services, and special offers.
- **Explore Menu:** Displays different food categories with images.
- **Healthy Food Section:** Promotes fresh and healthy food choices.
- **Delivery & Payment:** Showcases delivery information and supported payment methods.
- **Follow Us:** Displays social media icons.
- **Footer Section:** Includes website branding and contact information.
- **Responsive Layout:** Uses CSS Flexbox, media queries, and flexible layouts to support different screen sizes.

## 🛠️ Technologies Used

- HTML5 – For structuring the website.
- CSS3 – For styling, layouts, and responsive design.
- Google Fonts – For typography.
- Font Awesome – For icons.
